# Hand 模块使用指南

本目录包含了 hand 模块的使用示例，帮助您快速上手使用不同的手部控制功能。

## 文件说明

### 1. README.md
本文档，介绍 hand 模块的整体使用方法和示例文件说明。

### 2. move_joints_pos.py
测试 `move_joints_pos` 功能的完整示例，包括：
- 单手和双手模式测试
- 广播和非广播模式测试
- 自定义位置数据测试
- 手势执行测试
- 平滑过渡测试
- 手部回零测试

### 3. motor_usage_example.py
展示如何使用 `motor.py` 中的 Motor 类进行底层电机控制，包括：
- 电机连接和断开
- 单个电机控制
- 广播控制多个电机
- 电机状态查询
- 点动控制
- 紧急停止

### 4. gaia_hand_usage_example.py
展示如何使用 `core.py` 中的 GaiaHandAdapter 进行高级手部控制，包括：
- 手部连接管理
- 关节角度控制
- 手指控制
- 手势执行
- 运动学计算
- 电机状态监控

## 快速开始

### 1. 环境准备
确保已安装所需的依赖包：
```bash
pip install -r requirements.txt
```

# 安装模块
```bash
pip install -e .
```

### 2. 硬件连接
- 确保手部硬件已正确连接到串口
- 检查串口号和波特率设置

### 3. 运行示例
```bash
# 测试 move_joints_pos 功能
python move_joints_pos.py

# 测试底层电机控制
python motor_usage_example.py

# 测试高级手部控制
python gaia_hand_usage_example.py
```

## 模块架构

### 1. Motor 类 (motor.py)
- 提供底层的电机控制功能
- 支持串口通信协议
- 实现电机使能、角度设置、状态查询等功能

### 2. GaiaHandAdapter 类 (core.py)
- 提供高级的手部控制接口
- 基于 Motor 类实现
- 支持单手、双手模式
- 提供手势执行、运动学计算等功能

### 3. 统一接口 (core.py)
- `create_hand()` 工厂函数
- 支持多种手部类型（GaiaHand）
- 提供统一的控制接口

## 使用建议

1. **初学者**：建议从 `gaia_hand_usage_example.py` 开始，了解高级接口的使用
2. **进阶用户**：可以查看 `motor_usage_example.py`，了解底层控制机制
3. **调试问题**：使用 `move_joints_pos.py` 进行功能测试和问题排查

## 注意事项

1. 运行示例前请确保硬件连接正确
2. 注意串口号和波特率设置
3. 首次使用建议先执行手部回零操作
4. 使用紧急停止功能时请谨慎操作
5. 建议在安全环境下进行测试

## 故障排除

### 常见问题
1. **连接失败**：检查串口号和硬件连接
2. **通信超时**：检查波特率设置和硬件状态
3. **电机不响应**：检查电机使能状态
4. **位置控制异常**：检查角度范围和单位转换

### 调试方法
1. 查看日志输出
2. 使用串口调试工具
3. 检查硬件指示灯状态
4. 逐步测试各个功能模块
